# Audio contract — the SoundPack

Every sound and every piece of music in How to Fish is GENERATED by the
scripts in this directory (pure numpy/scipy synthesis, `soundfile` for OGG)
and delivered as one imported pack, `ReplicatedStorage/Assets/SoundPack`.
No Roblox library sounds. No hand-typed asset ids anywhere in `src/`.

This file is the source of truth that the generator, the Luau side and the
import checklist are all built against. Change a name here first.

## 1. Why bundles

Roblox caps audio uploads per month (about 100 with ID verification, 10
without) and every upload is a human clicking import and then checking that
a Sound ended up with the right Name. The game needs ~410 cues, 24 music
tracks and 9 beds, so one file per thing is not importable - and fifty files
is not pleasant either. What Roblox does NOT cap is length, beyond two
per-file limits: **under 7 minutes and under 20 MB**. So the pack is a
handful of long files and EVERYTHING IS A REGION OF ONE:

- **SFX**: the 17 logical category sheets (cues laid end to end with 150 ms
  of silence between them, exactly as before) are themselves concatenated
  into `audio_sfx_1.ogg`, `audio_sfx_2.ogg`, ... with 150 ms between sheets.
- **Music** (island themes, boss stems, stingers): packed into
  `audio_music_N.ogg` with 0.5 s of silence between tracks. A boss's `low`
  and `high` stem always land in the SAME bundle - the client crossfades
  between them for the length of a fight, and two bundles would mean two
  preloads and two streams for one piece of music.
- **Ambience**: the 9 beds into `audio_ambience_N.ogg`, same 0.5 s gaps.

The generator emits `src/Shared/Config/SoundSprites.luau` (GENERATED, like
`MeshColors.luau`):

```lua
SoundSprites.files = { audio_sfx_1 = true, ... }       -- the Sound names the pack needs
SoundSprites.cues.catchLegendary  = { file = "audio_sfx_1", start = 17.366, length = 2.577, loop = false }
SoundSprites.music.island_ice     = { file = "audio_music_5", start = 165.071, length = 160.000, loop = true }
SoundSprites.music.stinger_finale = { file = "audio_music_1", start = 372.286, length = 12.000, loop = false }
SoundSprites.ambience.amb_storm   = { file = "audio_ambience_2", start = 284.000, length = 66.000, loop = true }
```

Playback is one rule for all four: seek a CLONE of the bundle Sound to
`start`, stop at `start + length`. `Sound.Looped` is never used by anything -
it would loop the whole six-minute bundle. A `loop = true` region is looped
by the client with two alternating clones of the bundle: the second is
started at `start` about 120 ms before the first runs out and the two are
crossfaded equal-power, on a clock-driven schedule (`os.clock()`, never
`TimePosition`, which is quantised to the audio callback). The renders are
still authored as exact bar multiples with the reverb tail wrapped into the
head, so the join is continuous material - the crossfade only hides the seek.
`Sfx.luau` does the same for its sprites (60 ms there).

Budget: **11 uploads** - 2 SFX bundles (~9 min of cues), 7 music bundles
(~40 min), 2 ambience bundles (~11 min) - where the per-file layout would
have been 50. The packer targets 6:30 a bundle and `build.py` ASSERTS the
7:00 / 20 MB limits with margin (19 MB), so a bundle that would be rejected
is a build failure rather than an import failure. Music at 44.1 kHz stereo
OGG ~110 kbps ≈ 4.3 MB per 6:30 bundle.

## 2. Layout

```
assets/audio_gen/
  CONTRACT.md        this file
  synth.py           DSP toolkit (oscillators, noise, filters, envelopes,
                     Karplus-Strong, FM, reverb, delay, compressor/limiter,
                     stereo width, loudness normalise, OGG writer)
  cues.py            the cue registry: every SFX cue name, its category
                     sheet, loop flag, 2D/3D intent, description. Generators
                     register a render function per cue with @cue(...).
  sfx_*.py           render functions, one module per category (see §3)
  music_*.py         island themes, boss stems, ambience beds, stingers
  build.py           CLI: `python3 assets/audio_gen/build.py [--only sheet] [--check]`
                     renders the sheets and tracks, PACKS them into the
                     bundles, writes assets/audio/bundles/**,
                     assets/audio/manifest.json and
                     src/Shared/Config/SoundSprites.luau. `--check` renders
                     nothing and exits 1 if the registry, the Luau catalogue
                     (Sfx.luau CATALOGUE keys + MusicController track keys)
                     and SoundSprites.luau disagree, or if a bundle's audio
                     or layout has moved since the manifest.
assets/audio/
  bundles/audio_sfx_N.ogg       the sprite sheets, end to end (mono)
  bundles/audio_music_N.ogg     island themes, boss stems, stingers (stereo)
  bundles/audio_ambience_N.ogg  the beds (stereo)
  manifest.json                 bundles (duration, bytes, members), tracks, cues
  preview/                      NOT committed; short mp3/ogg renders for review
  .cache/                       NOT committed; the per-cue and per-track renders
```

The LOGICAL names have not changed and are still what the rest of this file
talks about: `sfx_<sheet>` is a sheet, `island_<id>` a theme,
`boss_<id>_low` / `boss_<id>_high` a stem pair (same length, same tempo,
same key, bar-aligned so the client crossfades between them mid-bar),
`stinger_*` the three cards, `amb_<mode>` the beds. They are members of a
bundle now rather than files of their own; `manifest.json` says which bundle
each one landed in and at what offset.

**Studio import - 11 files.** Bulk-import everything under
`assets/audio/bundles` (Asset Manager → Bulk Import → Audio), then drag them
all into a Folder named `SoundPack` under `ReplicatedStorage/Assets`. Each
becomes a `Sound` whose Name is the file's basename without extension - that
name is the lookup key (`SoundSprites.files`), so do not rename. The exact
set is:

```
audio_sfx_1  audio_sfx_2
audio_music_1  audio_music_2  audio_music_3  audio_music_4
audio_music_5  audio_music_6  audio_music_7
audio_ambience_1  audio_ambience_2
```

## 3. SFX cues

Naming: camelCase, unique across the whole game, exactly the key used in
`Sfx.play("<name>", pos?)`. A `__<voice>` suffix is a VARIANT of a base cue
(`bossSlam__pyrelisk`): the base cue is what code asks for; the client picks
the variant when a voice is active (`Sfx.setVoice("pyrelisk")` from
BossHudController when its bar is up, or `opts.voice` per call for creature
families). A variant that does not exist falls back to the base.

Sheet = category. `[loop]` = authored loop-safe, played via Sfx.loop.
`[2D]` = played in the player's ears, `[3D]` = positional (rollOff range in
the Luau catalogue, not here).

## 4. Music and ambience

### Island themes (`island_<id>`, loop, 2–3 min, distinct scale and palette)

All seven are NOCTURNES: a sampled grand (§6) at pp–mp with the sustain
pedal held for a bar or two at a time, 50–72 BPM, rubato, no drum kit and no
tappable pulse. Layered, but the layers are quiet; every synth is high-passed
at 120–170 Hz and the piano is the only instrument with a bottom octave. No
two themes share a scale, a chord language or an instrument set.

- `island_tropical` Starter Cove — F lydian ↔ mixolydian, 60 BPM, 4/4, 40
  bars. Grand, solo violin (late), celesta, harp arpeggios, warm synth pad,
  choir "ooh", shimmer. Warm and simple.
- `island_swamp` Blackmire Fen — D dorian with blues b3/b5/b7, 54 BPM, 4/4,
  37 bars. Low grand, celli, woodwind reed, a worn music box (two combs,
  nine cents apart), dark synth drone. Mysterious, humid.
- `island_ice` Frostmaw Reach — C lydian with whole-tone chords, 54 BPM,
  4/4, 36 bars. High grand, glass bells, far glockenspiel, high strings,
  slow synth arp, shimmer above 2 kHz, no middle register. Cold and still.
- `island_volcano` Ashfall Caldera — E phrygian dominant / harmonic minor,
  58 BPM, 4/4, 34 bars. A two-note grand ostinato in the bottom octave, soft
  brass, distant timpani, choir "ahh", filtered synth pulse. Hot, slow.
- `island_gloom` Gloomtrench — A minor that never confirms itself
  (min-maj7 + quartal stacks), 50 BPM, 4/4, 36 bars. CLOSE Grand, Rhodes far
  back, bowed-glass synth pad, solo violin harmonics. The sparsest. Dread.
- `island_wreck` Wreckwater — G aeolian/phrygian, slow 6/8 lament (dotted
  crotchet 44), 132 BPM eighths, 57 bars. Celli and solo violin carry the
  tune, grand underneath, accordion-ish reed synth, a sea-chime. Modal
  shanty cadences (bVII–i, bII–i), never a dominant.
- `island_maelstrom` The Maelstrom — D minor, open fifths and octatonic
  swells, 64 BPM, 4/4, 40 bars. String swells, choir "ahh", grand tremolo,
  a big high-passed synth pad, tubular bells. The end of the sea.

Islets have no theme of their own: the nearest main island's theme plays
softer; open sea plays `amb_sea` only, no music.

### Boss stems (`boss_<id>_low` / `boss_<id>_high`)

NOT nocturnes: 144–160 BPM, the grand playing an octave ostinato in its
bottom two octaves with the pedal UP, strings grinding a suspension over it,
brass, choir and real percussion (FL's orchestral timpani, a low tom, a
crash). Tension is harmonic — chromatic descending bass, re-struck
suspensions, tritones, a minor/major shift late in each drive — not volume.
A synth bass doubles the ostinato an OCTAVE UP, high-passed at 120 Hz, so
the grand still owns the bottom.

`low` is the phase-1 read (ostinato, strings, sparse timpani); `high` is the
same arrangement plus brass, choir, full percussion, an octave-up
countermelody and a per-boss bell layer. Identical length/tempo/key,
bar-aligned. Each boss quotes its island's mode: brinejaw D dorian,
old_gnashroot D dorian low, rimefang C minor with the ice theme's lydian 4
(and its glass bells), pyrelisk E phrygian with a saturated saw stack on the
brass, noctyss minor 9ths that erupt only in `high`, admiral_wrack G
aeolian/phrygian with the accordion and sea-bell, kraken D minor open fifths
with the Maelstrom's tubular bells.

### Stingers (regions of a music bundle, not looped)
`stinger_bossIntro` (the "RISES FROM THE DEEP" card, 4 s: a brass-and-piano
hit into a string swell that does NOT resolve), `stinger_victory` (boss down,
6 s: piano and strings settling onto a major 9th, with a celesta run),
`stinger_finale` (Kraken slain, 12 s: minor to major over a held Dmaj9, with
tubular bells and celesta). Same palette as everything else.

### Ambience beds (`amb_<mode>`, loop, 60–90 s, quiet)
amb_sea (open water: swell, wind, distant gulls) · amb_clear (cove: surf,
gulls, palms) · amb_mist (fen: insects, drips, frogs) · amb_blizzard (wind
howl, ice ticks) · amb_ash (rumble, crackle, fumaroles) · amb_summit (thin
wind, sub rumble) · amb_ghost (creaking hulls, low moan, water) · amb_storm
(rain wall, thunder rolls, surge) · amb_gloom (pressure hum, drips, far
clicks) · amb_heartchamber (an INTERIOR - the Pyrelisk's heart chamber:
a 45 BPM sub heartbeat felt more than heard, magma-glow hiss breathing
under it, drips on hot stone in a small room; no wind layer at all).
Client resolves the mode exactly as WeatherController.refresh
does; the theme sits over the bed.

## 5. Loudness and mastering

All SFX peak-normalised to −1 dBFS after a soft limiter; per-cue gain
balance lives in the Luau catalogue (`volume`), not the file. Music
loudness-normalised to about −16 LUFS (RMS proxy in synth.py), true peak
−1 dBFS. Ambience beds −24 LUFS. 44.1 kHz; SFX mono, music/ambience stereo.
Every render is deterministic (seeded) so re-running the generator produces
byte-identical files and `--check` can compare.

## 6. Sampled sources

The music (island themes, boss stems, stingers) is no longer purely
synthesised. Everything in `sfx_*.py` and `music_ambience.py` still is; the
MUSIC is played on real instruments, read at render time from the content
that ships inside FL Studio:

```
/Applications/FL Studio 2024.app/Contents/Resources/FL/Data/Patches/
  Packs/Instruments/Keyboard/Stage Grand/Stage Grand N.wav     N = 1..88
  Packs/Instruments/Keyboard/Close Grand/Close Grand N.wav     N = 1..88
  Packs/Instruments/Orchestral/Strings Section/OSTR *.wav
  Packs/Instruments/Orchestral/Strings Solo/VRZ Full Strings Vibrato (N).wav
  Packs/Instruments/Orchestral/Choir Ahh/ · Choir Ooh/ · Brass Section/
  Packs/Instruments/Orchestral/Woodwind Section/ · Keyboard/Rhodes/
  Packs/Legacy/Instruments/Hits/HIT_Ctim_C4.wav · HIT_Ctim_F3.wav · HIT_Orch.wav
  Packs/Drums/Toms/Alma Tom.wav · Drums/Cymbals/Overhead Crash.wav
```

These files are WAVs in name only: the `fmt` tag is 0x674F and the data
chunk is a whole OGG VORBIS stream, so `music.fl_decode` slices from the
first `OggS` and decodes that. `music.sample_map` builds the MIDI-to-file
map - `Stage Grand N` is MIDI `20 + N`, the numbered families are pitched by
YIN at import - and `music.verify_sample_maps()` asserts it with two
independent estimators (see the section 3e header in `music.py`).

**Licence basis.** FL Studio's bundled instrument and sample content is
licensed to the owner of the FL Studio licence for use in their own
productions, including commercial ones, as long as it is not redistributed
as samples. That is exactly what happens here: **no sample file is ever
copied into this repository.** The generator reads them from the installed
app on the machine doing the render, and what is committed is only the
finished `assets/audio/bundles/*.ogg` - musical works in which the content
is performed, which is the permitted use. Do not add any of these WAVs to
the repo, to `assets/`, or to a cache directory that is not gitignored.

**Fallback.** If the FL path is absent (`music.fl_available()` is False -
any machine without FL Studio 2024 installed), the generator prints a loud
warning to stderr and falls back to the synthesised section-3d piano and the
section-3c additive strings. The build still succeeds and still produces
eleven valid bundles; the audio will differ from the committed one, so a
`--check` run on such a machine will report the music bundles as changed.
Re-render on a machine with the content before committing bundles.
